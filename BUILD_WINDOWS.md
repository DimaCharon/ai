# Сборка Charon Code в один .EXE (Windows 10)

Результат: `dist\CharonCode-Setup-1.0.0.exe` (инсталлятор NSIS, ставится в
`%LOCALAPPDATA%\Programs\Charon Code`) и `dist\Charon Code.exe` (portable —
один файл, запускается без установки).

---

## 1. Подготавливаем ПК

1. **Node.js LTS** — https://nodejs.org (поставить галочки «Add to PATH»).
   Проверка:
   ```bat
   node -v
   npm -v
   ```
2. **Visual C++ Build Tools** — нужны, если на ПК нет компилятора (ставится
   автоматически при `npm install` electron в большинстве случаев; если нет —
   https://visualstudio.microsoft.com/visual-cpp-build-tools/ → «Desktop development
   with C++»).

## 2. Сборка

```bat
cd charon-code
npm install
npm run dist
```

electron-builder сам:
- скачает Electron для Windows;
- упакует `main.js`, `preload.js`, `src/`, `assets/` (иконку, шрифты, чим);
- сгенерирует иконку из `assets/icon.png`;
- соберет NSIS-инсталлятор и portable.

Готовые файлы — в папке **`dist\`**.

## 3. Запуск собранного приложения

- Инсталлятор: запусти `CharonCode-Setup-1.0.0.exe` → Next → установка.
- Portable: просто запусти `Charon Code.exe`.

## 4. Тесты

1. Регистрация → приветствие с твоим именем.
2. Вставь ключ OpenRouter (⚙) → выбери бесплатную модель → спроси что-нибудь.
3. Вставь куку Arena → «Обновить сессию» → группа «Arena AI · агенты» обновится.
4. Задай задачу → по завершении маскот вылезает из правого нижнего угла,
   машет, играет чим; клик — возврат.
5. 📁 Файлы / ❯_ Терминал — работают, подтверждения спрашиваются.

## 5. Если что-то пошло не так

| Проблема | Решение |
|---|---|
| `electron: command not found` / `electron.exe не найден` после `npm install` | `npm rebuild electron`, либо переустановить Node LTS |
| Установщик ругается на подпись | Файл НЕ подписан — SmartScreen: «Подробнее» → «Выполнить в любом случае» (нормально для локальной сборки). Для подписи нужен сертификат (~$100/год, опционально) |
| Антивирус подозревает electron-builder-сборку | Добавь папку `dist` в исключения; либо собери на чистом ПК и перенеси EXE |
| Прозрачный оверлей не показывается на втором мониторе | Оверлей всегда в рабочем углу основного дисплея (workArea) — ограничение v1 |
| `ETIMEDOUT` при `npm install` | Сеть/прокси: `npm config set registry https://registry.npmjs.org/`, отключи VPN на время установки |
| Хочешь другой каталог установки | При установке NSIS можно выбрать директорию (разрешено в конфигурации) |

## 6. Автообновление (опционально)

Не подключено (нет сервера). Если появится — electron-updater + GitHub Releases /
локальный feed.
