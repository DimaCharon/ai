# Сборка .exe НА САЙТЕ (без установки чего-либо на свой ПК)

Идея: серверы **GitHub Actions** сами собирают Charon Code.
Ты работаешь только в браузере: **github.com**.

Ничего не ставится на твой компьютер: ни Node.js, ни git, ни компиляторы.

---

## Шаг 1. Аккаунт и репозиторий (2 минуты)

1. Открой **github.com** → **Sign up** (бесплатно, можно через почту/GitHub).
2. Кнопка **`+`** (сверху справа) → **New repository**:
   - **Repository name**: `charon-code` (любое)
   - **Public** — безлимитное бесплатное время сборки
     (или **Private** — 2000 минут/мес бесплатно, это ~100 сборок)
   - галочки НЕ ставь → **Create repository**

## Шаг 2. Загрузка файлов проекта (через браузер)

1. В пустом репозитории нажми ссылку **«uploading an existing file»**.
2. Перетащи в окно **СОДЕРЖИМОЕ папки `charon-code`**
   (package.json, main.js, preload.js, папки `src`, `assets`, `uninstall.*`, …).
3. **Важно:** нужна ещё скрытая папка **`.github`** (в ней сценарий сборки
   `workflows/build.yml`). Если её не видно в Проводнике:
   *Вид → Отметки → Скрытые элементы* (или просто создай её по Шагу 2б).

**Шаг 2б (проще, если скрытые папки не показываются):**
1. Кнопка **Add file → Create new file**
2. В поле имени впиши с папками: `.github/workflows/build.yml`
3. Вставь содержимое файла `build.yml` (из этой папки проекта).
4. **Commit changes**

4. Внизу страницы — зелёная кнопка **Commit changes**.

> 🎉 С этого момента сборка запустится **сама** (workflow срабатывает на push).
> Если хочешь запустить вручную — см. Шаг 3.

## Шаг 3. Сборка (кнопкой или сама)

1. В репозитории вкладка **Actions**.
2. Слева workflow **Build Charon Code**.
   - При первой загрузке файлов сборка уже идёт (жёлтая крутящаяся иконка).
   - Вручную: кнопка **Run workflow** → подтверждение.
3. Смотри вживую, как сервер ставит Node, качает Electron и пачкает .exe.
   **Время: 10–20 минут** (зависит от очереди GitHub).

## Шаг 4. Скачивание готовых .exe

1. Когда кружок станет **зелёным ✓** — в конце записи:
   **Artifacts → `CharonCode-Windows`** → клик → скачается zip.
2. Внутри:
   - **`Charon Code Setup 1.0.0.exe`** — установщик (ставится в Programs)
   - **`Charon Code.exe`** — **portable**: один файл, ставится ничего не надо —
     кидаешь на рабочий стол/флешку и запускаешь.
3. Запускай на любом Windows 10+.

## Повторная сборка после правок

1. Правь файлы проекта локально.
2. Загружай изменённые в репозиторий (Add file / upload).
3. Сборка стартует сама → новые .exe в Artifacts (старые живут 30 дней).

---

## Что именно делает сценарий сборки

Файл: `.github/workflows/build.yml` (уже в проекте)

```
Windows-сервер GitHub
  → checkout файлов
  → Node.js 20
  → npm install            (electron + electron-builder)
  → npm run dist           (electron-builder: NSIS + portable)
  → artifact dist/*.exe    (скачиваешь)
```

## Если сборка упала (красный ✗)

1. Кликни по шагу с ✗ — откроется лог: там точная причина (обычно это
   опечатка в `package.json` или недоступный файл).
2. Ничего страшного не произошло — просто поправь файл и перезагрузи.
3. Если упало на «Установка зависимостей» из-за сети — просто **Run workflow**
   ещё раз (очередь GitHub бывает нестабильной).

## Частые вопросы

- **Нужен ли платный GitHub?** Нет. Public — бесплатно без лимита;
  Private — 2000 мин/мес бесплатно.
- **Нужен ли мне вообще компьютер с Windows?** Для сборки — нет (делает GitHub).
  Для запуска готового .exe — да, любой Windows 10+.
- **Мои ключи API попадут в GitHub?** Нет. Ключи вводятся уже в самом
  приложении (⚙) и лежат только в AppData на твоём ПК.
- **Можно ли собрать прямо здесь, в этом чате?** В принципе — да, но надёжнее
  и стандартнее через GitHub: у тебя остаётся история сборок и кнопка
  пересборки на любой случай.
