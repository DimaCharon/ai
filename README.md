# Charon Code

Десктопный AI-проводник для Windows 10 (Electron): тёмный интерфейс в стиле Claude Code,
кастомный титлбар с mac-кнопками, пиксельный маскот Charon (1:1 с оригиналом),
оверлей-маскот в правом нижнем углу рабочего стола и «контролируемый» доступ к
файлам и терминалу.

**Провайдеры:**
- **Arena AI (lmarena.ai)** — по сессионной куке: приложение смотрит список
  AI-агентов Арены и предлагает их, создаёт реальные чаты, ведёт лимит.
- **dahl.global** — DeepSeek-V4-Flash-0731, MiniMax-M2.7, GLM-5.3-Flash.
- **OpenRouter** — только бесплатные модели (`:free`), список живой.
- **XRouter (xkiro.com)** — 50+ бесплатных моделей (Qwen, MiniMax, Mistral,
  SenseNova, DeepSeek…), живой каталог с API, 👁 vision-модели.

**Code-режим:** совет из 4 самых сильных бесплатных моделей XRouter думает
параллельно, судья сводит в один вывод (раздел 6.2).
**Коннекторы:** GitHub и GitLab (репозитории → файлы → в чат / в проект),
Google Drive — с инструкцией по OAuth (раздел 6.3).

**Приватность:** регистрация, аккаунты, ключи и чаты хранятся **только на этом ПК**
(`C:\Users\<ты>\AppData\Roaming\Charon Code`). Никаких облаков.

## 1. УСТАНОВКА

### Вариант А — готовый EXE (если у тебя есть собранный installer)
1. Запусти `CharonCode-Setup-1.0.0.exe` (или перенеси `Charon Code.exe` portable-версии).
2. Готово: ярлык на рабочем столе + в меню Пуск.

Собрать EXE своими руками — см. **BUILD_WINDOWS.md**.

### Вариант Б — запуск из исходников (dev-режим)
Нужен [Node.js LTS](https://nodejs.org) (18+):
```bat
cd charon-code
npm install
npm start
```

---

## 2. ПЕРВЫЙ ЗАПУСК: РЕГИСТРАЦИЯ

1. Откроется экран входа. Вкладка **«Регистрация»**: имя пользователя (3–24 символа),
   пароль (от 4), повтор пароля → **Зарегистрироваться**.
2. Аккаунт создаётся **только локально** (файл `users.json` в AppData, пароль —
   scrypt-хеш). При следующем запуске — автовход, вкладка «Вход».
3. Вместо «striver» в приветствии теперь **твоё имя**: *What's up next, {ты}?*

Выйти из аккаунта: **⚙ Настройки → «Выйти из аккаунта»**.

## 3. НАСТРОЙКИ КЛЮЧЕЙ (⚙)

| Поле | Откуда взять | Зачем |
|---|---|---|
| OpenRouter · API key | https://openrouter.ai/keys (бесплатно) | бесплатные модели |
| dahl.global · API key | твой ключ | 3 кастомные модели |

и подтягивает свежие агенты Арены. Статус виден рядом: `активна` / `обновление…` / `нет`.

## 4. РАБОТА С ЧАТОМ

- **Модель** — кнопка в правом нижнем углу (или вкладка **Models**): выбираешь любую
  из трёх групп. Выбранная модель сохраняется.
- **Отправка** — Enter или кнопка. Работает движок **«1 нажатие = 1 гарантированный ответ»**:
  если нейросеть тормозит/рвёт соединение — приложение само переподключается
  (exponential backoff, до 10 попыток). Статус строки:
  `Ожидание ответа… Попытка 2/10 (Arena AI отвечает с задержкой, повторяем запрос)`.
- **Остановка** — кнопка **■** в поле ввода.
- **Критическая ошибка** — диагностическое окно на русском (причина: «Истекла сессия
  Arena AI», «Нет ключа…», «Превышен лимит…» и т.д.) + кнопка **«Переподключиться»**.
- **История** — кнопка **🕘 История**: все локальные чаты, продолжение любого из них,
  «＋ Новый чат».

### Авто-миграция чатов (лимит)
У каждого чата есть лимит сообщений (для Arena настраивается в ⚙, по умолчанию 30).
Когда чат наполнен, приложение **само**:
1. создаёт новый чат (у Arena — **реальный, на самом сайте**);
2. шлёт туда тестовый запрос и **убеждается, что новый чат отвечает**;
3. **копирует туда историю** старого чата;
4. убедившись, что новый работает — **удаляет старый** (на сайте + локально в архив).

Если проверка нового чата не проходит — старый остаётся нетронутым.

## 5. ФАЙЛЫ И ТЕРМИНАЛ

Кнопки **📁 Файлы** и **❯_ Терминал** в титлбаре открывают нижнюю панель.

**Файлы:**
- навигация по папкам, предпросмотр текста (до 2 МБ), редактирование;
- **💾 Сохранить** — только после подтверждения в модалке;
- **Выбрать…** — диалог выбора папки проекта; **Проводник** — показать в проводнике;
- чипы папок над полем ввода: кликабельные папки проектов (＋ добавляет новую,
  она же становится рабочей папкой терминала).

**Терминал (CMD / PowerShell):**
- выбор оболочки (CMD/PowerShell) и рабочей папки;
- перед каждым запуском — **подтверждение** с текстом команды;
- стриминг вывода, **Стоп** (kill процесса), **Очистить**.

## 6. МАСКОТ

- Мини-маскот в строке папок — живёт (моргает), **следит за курсором глазами**
  (тело стоит на месте) и машет, когда мышь рядом; клик — «призвать» оверлей.
  В ⚙: «Маскот: показывать», «Анимация», «Тихий чим» — всё по отдельности.
- **Оверлей**: когда задача завершена (включается в ⚙: «Маскот + чим при завершении»),
  прозрачное always-on-top окно в **правом нижнем углу над треем**: Charon
  вылезает из-за угла, **машет правой рукой**, играет **тихий спокойный чим**,
  затем замеряет (покачивание + моргание), **выкатываясь из угла с наклоном**.
  **Клик по маскоту** — фокус возвращается в приложение.

## 6.1 ВИДЕНИЕ ЭКРАНА (микроскриншоты)

Чат-API не смотрят «видео в реальном времени», поэтому формат — **микроскриншоты**:
свежий кадр экрана (JPEG, ~1280px, 150–400 КБ) прикладывается к сообщению, и
модель видит экран **в момент отправки**.

- Кнопка **📷 Экран** (рядом с полем ввода) — приложить скриншот к следующему
  сообщению (разово).
- Кнопка **👁 Live** — live-режим: к **каждому** сообщению автоматически
  прикладывается свежий микроскриншот.
- Работает только с моделями, помеченными **👁** в списке моделей
  (у XRouter/xkiro — 26 из 37 бесплатных: Mistral Large 3, Qwen3 VL Plus,
  MiniMax M3, DeepSeek V4.1 Flash и др.; у OpenRouter — те, что с vision).
  С «слепыми» моделями (dahl, часть остальных) режим просто не включится.
- Превью последнего кадра видно над полем ввода; в истории сообщение
  помечается 📷 (сам кадр в историю не пишется — чаты остаются лёгкими).
- Захват — встроенный `desktopCapturer` Electron, без доп. зависимостей.
  На Windows 11 при захвате ОС может показывать индикатор «идёт захват
  экрана» — это уровень системы, не приложение.

## 6.2 CODE-РЕЖИМ (совет моделей)

Кнопка **🧠 Code** (внизу, рядом с бейджем модели). Включил — и следующее
сообщение отвечает не одна модель, а **совет из самых мощных бесплатных
моделей XRouter (xkiro.com)**:

1. 4 модели думают **параллельно** (по умолчанию: `qwen3-coder-plus:free`,
   `deepseek-v4.1-flash:free`, `minimax-m3:free`, `qwen3.8-max:free` —
   состав подбирается динамически из живого free-каталога xkiro).
2. Судья (`qwen3.8-max:free`) сравнивает ответы и выдаёт **один итоговый
   вывод**, который стримится в чат как обычный ответ.
3. Отдельные ответы каждой модели сохраняются в сообщении и видны в
   свёртке **«🧠 Code: отдельные ответы моделей (N/M)»** под ответом.

Нужен ключ XRouter (`XTROUTER_API_KEY` в Настройках) — без него честная
диагностика. Если 1–2 модели отвалились (лимиты free) — совет работает на
остальных; требуется минимум 2 живых.

## 6.3 КОННЕКТОРЫ (GitHub / GitLab / Google Drive)

Кнопка **🔌 Коннекторы** в тулбаре — третья вкладка панели:

- **🐙 GitHub** — по Personal Access Token (scope `repo`): список своих
  репозиториев → дерево файлов → предпросмотр. Для файла:
  **💬 В чат** (файл улетает модели в контекст и остаётся в истории),
  **💾 В папку проекта** (без перезаписи: «имя (1).ext»),
  **📦 Скачать весь репо** (tarball → распаковка, до 500 МБ).
- **🦊 GitLab** — то же самое по Access Token (scope `read_api`).
- **📁 Google Drive** — требует OAuth-приложение, зарегистрированное на
  твоё имя (политика Google). В карточке — пошаговая инструкция;
  когда будут Client ID / Secret / refresh token — подключим полностью.

Токены хранятся **только локально** (settings.json в AppData) и уходят
только к соответствующему API. Распаковка .tar.gz — собственная, без
зависимостей; симлинки из архивов не раскладываются (защита от выхода
за папку).

## 7. УДАЛЕНИЕ

1. Положи `uninstall.bat` или `uninstall.ps1` (из этой папки) на ПК.
2. Запусти:
   ```bat
   uninstall.bat
   ```
   или
   ```powershell
   powershell -ExecutionPolicy Bypass -File uninstall.ps1
   ```
3. Скрипт: завершает процесс → удаляет каталог установки
   (`%LOCALAPPDATA%\Programs\Charon Code`) → удаляет **все данные**
   (`%APPDATA%\Charon Code`: аккаунты, ключи, куку, чаты) → снимает ярлыки →
   чистит реестр (запись об установке + автостарт).

**Ручное удаление** (если скрипт недоступен):
- Удалить программу: Пуск → Параметры → Приложения → Charon Code → Удалить
  (или вручную `%LOCALAPPDATA%\Programs\Charon Code`);
- Удалить данные: `%APPDATA%\Charon Code` (Win+R).

## 8. ГДЕ ЧТО ЛЕЖИТ (структура данных)

```
C:\Users\<ты>\AppData\Roaming\Charon Code\
  users.json      — локальные аккаунты (scrypt-хеши)
  session.json    — текущий вошедший аккаунт (автовход)

```

## 9. ЧЁСТНЫЕ ОГРАНИЧЕНИЯ

- **Arena AI не имеет публичного API.** Модуль `arena.js` ходит на её
  веб-эндпоинты от имени твоей сессии. Путь в одном блоке `ARENA_CFG.endpoints` —
  если сайт изменит API, диагностическое окно скажет, какой шаг сломался,
  и блок правится в одном месте. Куки могут истекать — тогда «Обновить сессию».
- Лимит чата в Arena (`arenaLimit`) — укажи свой реальный в настройках.
- Стриминг/лимиты бесплатных моделей OpenRouter — у провайдера; при 429 движок
  ждёт и повторяет.
