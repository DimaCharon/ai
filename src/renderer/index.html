What's new · 1.0.8

      
    
        
  • 1.0.8 — ИИ теперь АГЕНТ: прикрепи папку (чип) или выбери проект — ИИ видит ВСЕ файлы в ней (список + содержимое уже в контексте), может читать любые (```read) и редактировать (```edit, с твоим подтверждением). Инструменты отрабатывают в петле: сделал — увидел результат — доработал, пока задача не закрыта.
    • 
        
  • 🌐 Браузер ИИ — ТОЛЬКО инкогнито: по команде ```browse: URL``` Charon открывает страницу в отдельном чистом профиле (ни одна твоя кука/пароль не участвует), отдаёт текст ИИ и закрывает окно; после каждого промта все окна закрываются. Тумблер: видимое окно / тихо в фоне (Настройки).
    • 
        
  • 📁 Проекты + 🧠 Память: проект = папка + своя память (отдельная на проект); глобальная память — 1 на все чаты. ИИ видит память в каждом чате и пишет в неё сам; вкладка «Память» — читать и править вручную. Фильтр чатов по проекту в Истории.
    • 
        
  • 🧠 Код-режим: совет САМЫХ ЛУЧШИХ моделей — теперь не только free: XRouter free + dahl (MiniMax M2.7, DeepSeek V4 Flash) + OpenRouter (топ :free) — по тем ключам, что у тебя в настройках. Судья — сильнейшая из доступных.
    • 
        
  • 🔑 XRouter: несколько ключей — вставь несколько XTROUTER_API_KEY (＋ Ещё ключ). Лимит на одном кончился (429) → авто-переключение на следующий; рабочий ключ запоминается.
    • 
        
  • 🧩 Плагины по ссылке: вкладка «Плагины» → вставь https://github.com/автор/плагин → установилось. Плагин = команды /имя (в чате, с автодополнением) + контекст для ИИ.
    • 
        
  • 🛠 Режим Self: ИИ читает и правит файлы САМОГО Charon Code (режим в строке чата). После правок — кнопка «Перезапустить». Чтобы правки сохранялись: установка НЕ в Program Files или запуск от админа.
    • 
        
  • 🧹 Деинсталлятор «под чистую»: новый uninstall.bat — ищет и убирает ВСЁ приложение со ВСЕХ дисков (реестр + AppData + Program Files + каталог установки + временные файлы), с подтверждением.
    • 
        
  • 1.0.7 — прикреплённые папки: клик по папке (чипу) или «＋» — панель Файлы открывается сама и сразу показывает содержимое; файлы можно просматривать и редактировать (сохранение с подтверждением).
